# Adaptive Watch release (fallback)

The product that preceded Ortru: a single-case-at-a-time review interface (station platform flagship case plus three
secondary examples) with a 177-second narrated film. It is preserved, unchanged in behavior, on the branch
`release/adaptive-watch-submission` as a working fallback until the product owner approves Ortru.

These documents describe that release (its launch scripts, ports and checks live on that branch, not here). They are kept
for the record and are **not** current instructions for Ortru.
