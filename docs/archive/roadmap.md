# Scope and gates — Hafnia Hackathon 2026

## v0.1 — validated native round-trip

Python submits recorded video to Hafnia, retrieves a response and parses a decision. The saved gateway rule creates a native XProtect analytics event and alarm. Both the built-in event test and Python-triggered workflow were verified in Smart Client on the Windows hackathon VM (XProtect Corporate 2026 R1).

## v0.2 — Scene Contracts

Version-controlled observable conditions, reusable assessment, SQLite observations and operator review cases, explicit recorded-interval evaluation, existing-result ingestion, and read-only Events/Alarms retrieval with conservative local association. See [architecture, commands, limitations and live gates](scene-contracts-v02.md).

Implementation and deterministic offline checks are complete. Windows execution, actual captured response fixtures, deployed REST authentication/schema, and alarm association remain live verification gates. No claim of working VM REST integration is made.

## Deferred

Continuous monitoring, automatic incident separation, XProtect-initiated webhooks, multi-camera incidents, React UI, training, C# plugins and automatic alarm dismissal. Future scope requires evidence from the v0.2 VM gates; local review state never claims physical incident resolution.
