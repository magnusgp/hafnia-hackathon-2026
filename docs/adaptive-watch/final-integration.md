timestamped CV evidence and Hafnia interpretation of the same recording. This is
an operator review tool; no independently measured accuracy improvement is claimed.

## Exact proposed Management Client configuration

These are instructions for an explicitly authorized operator. No definitions or
settings have been changed by this implementation.

1. In **Rules and Events → Analytics Events**, add the exact name
   `Adaptive Watch Sidewalk Obstruction`. Set its description to
   `Potential sidewalk obstruction — review required`. Save only after authorization.
2. In **Alarms → Alarm Definitions**, add a definition named
   `Adaptive Watch — sidewalk review (e-scooter)`.
   Set Triggering event type to **Analytics Events**, then select the exact event
   above. Sources: only `escooter_left_across_sidewalk`, verified camera GUID
   `8B27A358-DF7E-496B-8DAC-722D0F4B151C`. Do not include the bin or all cameras.
3. Instructions: `Potential sidewalk obstruction — review required. Review the
   recorded interval, stationary object and pedestrian zone. Partial box overlap
   does not establish blocked clearance. Synthetic loop reset is not removal.`
   Initial priority: the existing **Medium** priority, after confirming its local
   level in Alarm Data Settings. Do not create or renumber priority levels.
   Time profile: **Always** for the operator-invoked demo. Leave automatic closure
   and events triggered by the alarm unset; no owner/account changes.
4. In Smart Client **Alarm Manager**, select the alarm list and expose available
   columns for ID, time, source, message/name, priority, state and assigned owner.
   Confirm the alarm detail shows the instructions and exact scooter camera.
   Record displayed timezone; compare source UTC times and playback explicitly.
5. After separate approval of the exact XML SHA-256, send one event. Open the
   resulting alarm preview and playback at the source timestamp. Check any
   available bounding-box display option in that view. Record whether the single
   `ObjectList/Object/BoundingBox` rectangle appears at the matching frame.
   Capture a screenshot and alarm ID. Do not claim a live tracking overlay from
   one static event box. XML support does not prove this installation renders it.

The existing Analytics Receive endpoint must already work. Do not alter its port,
allowed-address list, services or firewall. An empty HTTP 200 means transport
acceptance; it does not confirm a native alarm or its overlay.
